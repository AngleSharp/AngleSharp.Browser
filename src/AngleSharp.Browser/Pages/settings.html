Settings

Changes apply to every window opened after saving them.

General

Start page The page a new window opens.
Appearance The browser's theme, also reported to pages as their preferred color scheme.

Content

Default font size In CSS pixels, used where pages do not set one.

Privacy and data

Cache directory Where browsing data is kept. Leave empty for the default location.

Network

User agent How the browser introduces itself to sites. Leave empty for the default of AngleSharp.
Default headers Sent with every request, one "Name: value" per line, e.g., Accept-Language: de-AT.
