## Recommended Reading Order

If you are new to AngleSharp.Browser, this order gives a practical ramp-up:

1. [Getting Started](general/01-Basics.md) for setup and first working code.
2. [Examples](tutorials/02-Examples.md) for copy-paste recipes.
3. [Avalonia Control](general/06-Avalonia.md) if you want to show pages in a desktop application.
4. [Browser Engine](general/02-Engine.md) and [Configuration](general/05-Configuration.md) to understand threading, navigation and profiles.
5. [Rendering](general/03-Rendering.md), [Input](general/04-Input.md) and [Writing a Custom Host](tutorials/03-Custom-Host.md) to integrate another UI framework.
6. [API Documentation](tutorials/01-API.md) as a reference and the [FAQ](tutorials/04-Questions.md) for common pitfalls.

## What You Can Do With AngleSharp.Browser

Typical use cases include:

- Taking screenshots of pages without a display, entirely in .NET.
- Driving pages in tests: clicking, typing, scrolling, and inspecting the DOM afterwards.
- Embedding a web view without a native browser dependency in an Avalonia application.
- Showing your own UI written in HTML and CSS, wired up with .NET event handlers.
- Building browser-like tools with history, profiles, multiple windows and diagnostics.
